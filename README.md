# Spoken-Digits-Recognition-Using-Deep-Learning
## Dataset

The project was trained on the EE708 Spoken Digit Recognition dataset.

Training data:
- 37,800 labelled audio samples
- 10 classes corresponding to digits 0–9
- Audio sampled at 16 kHz

Test data:
- 16,200 audio samples

The dataset is not included in this repository due to its size.
Update the dataset paths in the notebook before running locally.
